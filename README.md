# 🎯 Word Guess

A modern and simple word guessing game built with **Python** and **CustomTkinter**.

Choose a category, guess the hidden word letter by letter, and try to complete it before you run out of attempts.

---

## ✨ Features

- 🎲 **Random / Mixed** word category
- 🐾 **Animals** category
- 🍔 **Food** category
- 🌍 **Countries** category
- 📦 **Objects** category
- ⌨️ On-screen QWERTY keyboard
- 🖥️ Clean and modern dark gaming UI
- 🎮 Keyboard and Enter-key support
- 🏆 Win / Game Over screens
- 📚 Built-in How to Play tutorial
- ⚡ Standalone Windows `.exe` — no Python installation required

---

## 🎮 How to Play

1. Choose a category.
2. A random word will be selected.
3. Guess the word one letter at a time.
4. Correct guesses reveal the letters.
5. Incorrect guesses reduce your remaining attempts.
6. Complete the word before running out of attempts to win!
